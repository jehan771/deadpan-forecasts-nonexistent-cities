# Deadpan Forecasts for Cities That Do Not Exist

One line, 150 characters: a deadpan weather forecast for Wimpleton, a city that
does not exist — 13 degrees and, from four, a 70% chance of rain that only falls
on people who forgot an umbrella; the rest stay dry out of spite.

The program (`main.ts`) writes that single line to `/output/entry.txt`, asserting
the competition gate first (1–160 characters, single line, not only whitespace)
and verifying the output by reading it back. Deterministic: no randomness, no
network, no input — every run writes byte-identical output.
